# 🛒 D'ACCORD — E-commerce de Cosméticos com Inteligência Artificial

> **Beleza guiada pela sua pele.** Uma experiência editorial de curadoria e recomendação inteligente de cosméticos que transforma foto, contexto e preferências em escolhas claras e coerentes.

---

## 📋 Sobre o Projeto (TCC Etec)
O **D'Accord** é o projeto de Trabalho de Conclusão de Curso (TCC) desenvolvido na ETEC Extensão Balneário Maracanã pelos alunos do curso técnico de Informática para a Internet. A plataforma unifica um sistema web de e-commerce voltado para o setor de cosméticos naturais com um assistente virtual inteligente (**Mia**), projetado para auxiliar os usuários a encontrarem os produtos ideais para o seu tipo de pele sem "achismos".

---

## 🚀 Funcionalidades Principais
* **Catálogo Dinâmico:** Listagem completa de produtos de cosméticos com filtros avançados.
* **Assistente Virtual (Mia):** Chatbot inteligente integrado para suporte ao cliente e recomendação de rotinas de *skincare*.
* **Área do Cliente / Autenticação:** Sistema seguro de cadastro, login e gestão de carrinho de compras.
* **Layout Responsivo:** Interface moderna, fluida e adaptada para dispositivos móveis e desktops.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi desenvolvido empregando as seguintes tecnologias e ferramentas:
* **Front-end:** HTML5, CSS3, JavaScript (com foco em componentização e responsividade).
* **Back-end:** Node.js / JavaScript para a lógica da aplicação e rotas.
* **Banco de Dados:** MySQL / MySQL Workbench para o gerenciamento relacional de usuários, produtos e pedidos.
* **Controle de Versão:** Git e GitHub para colaboração e gestão do código-fonte.

---

## 📂 Estrutura do Repositório

* `src/` — Arquivos principais de interface e front-end.
